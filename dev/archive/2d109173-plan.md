### The mechanical bar (per area task)

Two parts (D4-revised): the **committed `docs-mechanical` gate** — three low-self-rot
checkers (M2 link/anchor resolver, M3 citation-existence, M5 projection-freshness) landed
under `scripts/` by the Group-A enabler — and two **embedded** checks (M1, M4) whose exact
commands below are re-stated in each area task's description at breakdown. Each task
substitutes its own footprint for `<AREA>` (a space-separated list of files and/or
directories). Every check states its expected-clean output. All are deterministic. For M2
and M3, the command blocks below are the reference implementations the enabler hardens into
the committed scripts.

**Guard (run first, always):** the checks trust `jit --schema`; the binary must match `HEAD`.

```bash
cargo install --path crates/jit --force >/dev/null 2>&1
BIN_COMMIT=$(jit --version | grep -oE 'commit [0-9a-f]+' | awk '{print $2}')
case "$(git rev-parse HEAD)" in
  "$BIN_COMMIT"*) echo "OK: binary at HEAD" ;;
  *) echo "STALE BINARY — rebuild before trusting --schema" ;;
esac
```

(Prefix match against the full HEAD SHA, so the check is independent of git's short-SHA
abbreviation width.)

**M1 — command/flag inventory vs `--schema` (REQ-02, and the reference for REQ-05; embedded).**
Stays embedded and adjudicated rather than committed: its oracle is incomplete pending the
`--schema` completeness follow-up (aliases, global flags, full `State` enum — Group C), so a
committed differ would misreport valid aliases as drift; once that follow-up lands, a
committed diff becomes trivial (D4-revised). Reference inventories the auditor diffs each
documented command section against:

```bash
# 27 top-level families (REQ-05: every one needs a doc home)
jit --schema | jq -r '.commands | keys[]' | sort
# flags for one family, e.g. issue (repeat per family the area documents)
jit --schema | jq -r '.commands["issue"].subcommands | to_entries[] | "\(.key): \(.value.flags|map(.name)|join(", "))"'
```

Invented-surface guard — any `--flag` used in the area's docs that is not a real jit flag
(catches drift class 6). Expected residue on a clean area (not defects): (a) non-jit tool
flags (`cargo`, `npm`, `git`, `jq`); (b) real jit surface that `--schema`'s `.flags[].name`
traversal omits — clap `visible_alias` flag forms (e.g. `--add-label`,
`crates/jit/src/cli.rs:986`; `--title`, `cli.rs:1827`) and the global
`--help`/`--schema`/`--version` flags; (c) grep truncations of hyphen-adjacent prose or
multi-part flag mentions (e.g. a `--clear-…` fragment). **Adjudication rule: `--schema` alone
is not a sufficient oracle for the flag surface.** Before a residual flag is declared
invented (a drift-class-6 finding), validate it against the clap definitions in
`crates/jit/src/cli.rs` — the aliases live there; only a flag absent from both `--schema`
and `cli.rs` is a defect:

```bash
comm -23 \
  <(grep -rhoE '\-\-[a-z][a-z0-9-]+' <AREA> | sort -u) \
  <(jit --schema | jq -r '[.. | objects | .flags? // empty | .[].name] | unique | .[]' | sed 's/^/--/' | sort -u)
```

**M2 — link + heading-anchor resolver (REQ-02; committed script, `docs-mechanical` gate).**
Parses every markdown link and intra-document anchor in the audited surface and resolves
repo-relative targets, reproducing GitHub anchoring (lowercase, strip punctuation keeping
word-chars/hyphens, spaces→hyphens **one-to-one** so em-dash gaps become `--`). Low self-rot
by design: links and headings are both derived live from the tree at runtime; the script
encodes no product facts. Expected clean output: `OK: all links and anchors resolve`, exit 0.
Reference implementation:

```bash
python3 - <AREA> <<'PY'
import os, re, sys
roots = sys.argv[1:]; files=[]
for r in roots:
    if os.path.isfile(r): files.append(r)
    else:
        for dp,_,fns in os.walk(r):
            files += [os.path.join(dp,f) for f in fns if f.endswith('.md')]
def slugs(path):
    out=set(); fence=False
    try: text=open(path,encoding='utf-8').read()
    except OSError: return out
    for line in text.splitlines():
        if line.lstrip().startswith('```'): fence=not fence; continue
        if fence: continue
        m=re.match(r'#{1,6}\s+(.*)', line)
        if m:
            s=re.sub(r'[^\w\s-]','',m.group(1).strip().lower()).replace(' ','-').strip('-')
            out.add(s)
    return out
bad=[]; link=re.compile(r'\[[^\]]*\]\(([^)]+)\)')
for f in files:
    d=os.path.dirname(f)
    for t in link.findall(open(f,encoding='utf-8').read()):
        t=t.strip()
        if t.startswith(('http://','https://','mailto:')): continue
        path,_,anchor=t.partition('#')
        tgt=f if path=='' else os.path.normpath(os.path.join(d,path))
        if path and not os.path.exists(tgt): bad.append(f'{f}: missing target -> {t}'); continue
        if anchor and anchor not in slugs(tgt): bad.append(f'{f}: unresolved anchor -> {t}')
print('\n'.join(bad) if bad else 'OK: all links and anchors resolve')
PY
```

(First-pass resolver: it does not synthesize GitHub's `-1`/`-2` suffixes for repeated
headings, so an "unresolved anchor" against a duplicated heading is auditor-adjudicated, not
an automatic finding.)

**M3 — source-path + `@/…` citation existence (REQ-02, REQ-06; committed script,
`docs-mechanical` gate).** Extracts path-like tokens and tests existence, resolving `@/…`
citations live via `jit item show`. The placeholder filter is a pattern **class** (`<…>`,
`{…}`, globs) — never a file allowlist, so the script encodes no product facts and cannot
rot as paths move. Expected clean output:
no `DANGLING:` lines, and `MISSING:` lines only for placeholder/glob path notation — paths
containing `<…>`, `{…}`, or `*` (e.g. `.jit/issues/{id}.json`, `.jit/schemas/*.json`,
`.jit/config/gate-presets/<name>.json`, `crates/jit/tests/*.rs`) are expected residue, not
defects; on the current tree such benign lines appear in 4 of 5 areas. The committed script's
pattern-class filter suppresses them mechanically; the reference pipeline below emits them for
the auditor to adjudicate. Genuine defects do occur amid this noise (e.g. `.jit/claims.jsonl`
cited in `cli-commands.md` — claims actually live under `.git/jit/`), so every `MISSING:` line
without placeholder/glob notation is a finding. Line-number suffixes the auditor spot-opens.
Reference implementation:

```bash
# file-path citations in backticks must resolve
grep -rhoE '`[^`]+`' <AREA> | tr -d '`' \
  | grep -E '^(crates|docs|web|mcp-server|scripts|\.jit|\.github)/' \
  | grep -E '\.(rs|toml|json|jsonl|md|ts|tsx|js|sh|yml|py)(:[0-9]+(-[0-9]+)?)?$' \
  | sed -E 's/:[0-9].*$//' | sort -u \
  | while read -r p; do [ -e "$p" ] || echo "MISSING: $p"; done
# addressable-item citations must resolve
grep -rhoE '@/[a-z][a-z-]*/[a-zA-Z0-9-]+' <AREA> | sort -u \
  | while read -r a; do jit item show "$a" >/dev/null 2>&1 || echo "DANGLING: $a"; done
```

**M4 — diagram-shaped-art check (REQ-04, per scope decision D3; embedded).** Stays embedded:
REQ-04 is already satisfied (investigation §4), so a committed checker would carry near-zero
recurring value (D4-revised). Box-drawing chars only
(U+2500–257F); inline unicode-arrow prose is out of scope. Every hit must fall inside a
directory-tree listing or a verbatim-CLI-output fence (the carve-out at
`doc-review-prompt.md:65`); any hit forming a hand-drawn box/flow diagram is a REQ-04
violation to convert to Mermaid. Expected: all hits are trees/CLI output (record which).
M4's mechanical reach is box-drawing characters; ASCII arrow figures (`-->` art outside
Mermaid fences) and multi-line `→` spines are detected by the scoped `doc-review` reviewer,
whose prompt enforces the Mermaid mandate for all diagram forms (`doc-review-prompt.md:65`).

```bash
grep -rnP '[\x{2500}-\x{257F}]' <AREA>
```

**M5 — projection-freshness diff (REQ-06; committed script, `docs-mechanical` gate).**
Re-runs the projectors and diffs their configured targets (`AGENTS.md` invariant region,
`docs/reference/rules-and-gates.md` — investigation §5), enforcing
`@/inv/single-source-prose`: a stale projected region fails the gate. Low self-rot: targets
come from the live `[invariant_projection]`/`[rules_gates_projection]` config, both sides
derived at runtime. Expected clean output: no diff, exit 0. Reference implementation:

```bash
jit invariant render && jit reference render \
  && git diff --exit-code -- AGENTS.md docs/reference/rules-and-gates.md \
  && echo "OK: projections fresh"
```
