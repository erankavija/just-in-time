# JIT v1.0.0

The first stable release of Just-In-Time (JIT). [The product
documentation](../index.md) describes the tracker; this note records what the
release publishes and what adopters can expect of it.

## Release assets

[What a release publishes](../reference/release-policy.md#what-a-release-publishes)
lists every asset this tag carries and the guide that installs each one. Both
license texts, [LICENSE-MIT](../../LICENSE-MIT) and
[LICENSE-APACHE](../../LICENSE-APACHE), are among them.

## Packaging

v1.0.0 publishes one GitHub release and nothing else: no package-registry
version, no container-registry image tag, and no source distribution beyond the
source archives GitHub generates for the tag itself. Adopters install the
`@erankavija/jit-mcp-server` MCP server from its release tarball, following
[MCP Integration](../how-to/mcp-integration.md).

## Compatibility

One product version spans every supported capability. [The product
compatibility record](../reference/compatibility.md) enumerates that capability
set and draws the boundary between the product version and the independent
format version that governs repository data.

## Upgrade expectations

An upgrade replaces the installed artifacts together and leaves repository data
in place. [The compatibility record's upgrade
expectations](../reference/compatibility.md#upgrade-expectations) state what
that requires of an adopter.

## Installation

[The installation guide](../../INSTALL.md) is the canonical home for every
installation command, and [the deployment guide](../how-to/deployment.md)
covers running the server and web UI.
